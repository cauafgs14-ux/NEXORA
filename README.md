📌 Sobre o projeto

O Nexora é um projeto desenvolvido com foco em tecnologia, organização e inovação. Seu objetivo é oferecer uma experiência simples, moderna e intuitiva para seus usuários.

✨ Funcionalidades
🔐 Sistema de login
📝 Sistema de questionários
🧠 Lógica e processamento de informações
📑 Navegação por abas (Tabs)
🎨 Interface personalizada
🧪 Testes automatizados

HTML5
CSS3

Node.js
Git e GitHub

⚙️ Como executar
Clone o repositório:
bash
git clone URL_DO_SEU_REPOSITORIO

Entre na pasta:
bash
cd Nexora

Instale as dependências:
bash
npm install

Inicie o projeto:
bash
npm start

🧪 Testes

Para executar os testes:

bash
npm test

🔄 Integração contínua

O projeto utiliza GitHub Actions para:

Verificar a sintaxe JavaScript.
Instalar dependências.
Executar testes automatizados.
Validar alterações enviadas ao repositório.
